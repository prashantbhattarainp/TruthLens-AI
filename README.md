# TruthLens AI

TruthLens AI is a research-oriented platform for explainable fake news detection in Indian digital media.

## Overview

The project will provide a modular web platform with a browser-based user interface, a Node.js application backend, and an independent Python machine-learning service.

## Repository status

The repository landing page is established. Development work is integrated through the `develop` branch and reviewed through milestone feature branches.
