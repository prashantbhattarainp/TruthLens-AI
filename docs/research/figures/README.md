# Phase 4.1 and Phase 4.5 Research Figures

All figures are 300-DPI, generated by `scripts/research/generate_phase_4_1_xai_report.py`, and are linked to [XAI_ARTIFACT_MANIFEST.json](../XAI_ARTIFACT_MANIFEST.json).

| Figure | Purpose |
| --- | --- |
| `shap-global-summary.png` | Mean absolute zero-reference SHAP values over the training-only reference cohort. |
| `shap-feature-importance.png` | Signed aggregate SHAP contribution directions. |
| `top-feature-rankings.png` | Signed global LinearSVC coefficient ranking. |
| `lime-local-example.png` | Synthetic-input LIME margin-surrogate example. |
| `shap-local-waterfall-example.png` | Synthetic-input additive local SHAP waterfall. |

The figures contain no raw training documents or identifiers. They explain model behaviour only and must be read with [XAI_LIMITATIONS.md](../XAI_LIMITATIONS.md).

The final publication captions, sources, and interpretation limits are consolidated in the [Phase 4 figures index](../publication/FINAL_FIGURES_INDEX.md).

## Phase 4.5 reliability figures

All Phase 4.5 figures are 300-DPI aggregate-only PNGs generated by `ml.reliability_evaluation.run_evaluation`. [PHASE_4_5_ARTIFACT_MANIFEST.json](../PHASE_4_5_ARTIFACT_MANIFEST.json) records figure hashes. The calibration figures display a non-fitted sigmoid-margin diagnostic, not calibrated confidence.

| Figure | Purpose |
| --- | --- |
| `phase-4-5-calibration-curve.png` | Margin-proxy calibration curve diagnostic. |
| `phase-4-5-reliability-diagram.png` | Margin-proxy reliability bars and histogram. |
| `phase-4-5-robustness-comparison.png` | Perturbation coverage and prediction-flip rates. |
| `phase-4-5-perturbation-performance.png` | Synthetic-stress accuracy and Macro F1. |
| `phase-4-5-error-distribution.png` | Aggregate descriptive-theme error counts. |
| `phase-4-5-bias-analysis.png` | Length/topic-keyword Macro F1 diagnostics. |
| `phase-4-5-ablation-study.png` | Inference-only preprocessing/bigram ablation diagnostics. |
| `phase-4-5-explanation-stability.png` | Top linear-contribution overlap under perturbations. |
