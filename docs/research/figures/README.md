# Phase 4.1 XAI Figures

All figures are 300-DPI, generated by `scripts/research/generate_phase_4_1_xai_report.py`, and are linked to [XAI_ARTIFACT_MANIFEST.json](../XAI_ARTIFACT_MANIFEST.json).

| Figure | Purpose |
| --- | --- |
| `shap-global-summary.png` | Mean absolute zero-reference SHAP values over the training-only reference cohort. |
| `shap-feature-importance.png` | Signed aggregate SHAP contribution directions. |
| `top-feature-rankings.png` | Signed global LinearSVC coefficient ranking. |
| `lime-local-example.png` | Synthetic-input LIME margin-surrogate example. |
| `shap-local-waterfall-example.png` | Synthetic-input additive local SHAP waterfall. |

The figures contain no raw training documents or identifiers. They explain model behaviour only and must be read with [XAI_LIMITATIONS.md](../XAI_LIMITATIONS.md).
