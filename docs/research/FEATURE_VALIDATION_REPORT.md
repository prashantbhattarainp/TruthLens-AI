## Matrix validation strategy

Each generated matrix produces a report containing:

- vocabulary size and row/column dimensions;
- nonzero count, density, and sparsity;
- all-zero feature-vector count and rate;
- CSR-array memory consumption in bytes;
- recorded feature-processing duration; and
- explicit pass/fail checks for dimensional consistency, vocabulary presence, configured empty-row tolerance, memory limit, and duration recording.

The report is written even when a fitted matrix fails the configured thresholds. A corpus that cannot produce any vocabulary raises an explicit extraction failure rather than producing a misleading empty artifact.
