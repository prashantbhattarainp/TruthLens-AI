# User Guide

## Analyze content

1. Select **Predict** from the navigation.
2. Enter a headline and article text.
3. Ensure the article contains at least 100 characters.
4. Select **Analyze content**.
5. Review the classification, summary, and contributing words.
6. Check important claims with reliable independent sources.

## Interpret results

The result is an automated content-assessment signal. It is not proof that a claim is true or false, and it should not be the only input to an important decision. Explanation details show which terms influenced the automated classification; they do not prove why a claim is factually correct or incorrect.

## Dashboard

Select **Dashboard** and choose **Refresh service status** to check whether the backend and ML service are available. The dashboard does not show personal activity, saved predictions, or a usage history.

## Privacy

Avoid submitting sensitive personal information or confidential material. This version does not provide accounts or saved predictions.
