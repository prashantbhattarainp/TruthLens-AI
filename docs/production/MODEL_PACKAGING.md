The package is generated by `scripts/production/package_phase_3_10_champion.py`. It reads the governed Phase 3.9 artifact, but does not read raw data or perform training, evaluation, tuning, calibration, or model selection. Packaging refuses to overwrite an existing version directory.

## Contents

| File | Role |
| --- | --- |
| `model-pipeline.joblib` | Frozen TF-IDF + `LinearSVC` inference pipeline. |
| `vectorizer.joblib` / `classifier.joblib` | Independently packaged inspection components. |
| `label-mapping.json` | Fixed `0=REAL`, `1=FAKE` mapping; no label encoder is applicable. |
| `feature-configuration.json` | Frozen TF-IDF version 1.0.0 configuration. |
| `preprocessing-configuration.json` | Frozen conservative English preprocessing configuration version 1.0.0. |
| `model-metadata.json` | Model, dataset, versions, timestamp, experiment/optimization IDs, metrics, and limitations. |
| `manifest.json` | SHA-256 hashes for every package content file. |

On load, the service requires every file, checks the manifest hashes, validates metadata identity fields, validates the pipeline step names, and instantiates the frozen preprocessing policy. A missing, unreadable, altered, or incompatible package leaves the service alive but not ready; `/ready` returns a standardized `503` error.

## Safety boundary

The package is a versioned internal integration artifact only. The Linear SVM decision score is not a calibrated probability. It must not be shown as confidence, a risk assessment, or a factual verdict. The candidate is untested after tuning and remains subject to the dataset licence and scope restrictions.
