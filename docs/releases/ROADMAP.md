# Roadmap after v1.0.0-RC1

## Phase 6 entry conditions

Phase 6 must start only after approval and a governance decision that defines scope, owners, data rights, validation protocol, and release criteria. RC1 does not itself satisfy those conditions.

## Governed priority areas

1. New governed data with documented rights, representative scope, and an untouched evaluation design.
2. Post-tuning protected evaluation, calibration, robustness, fairness, drift, and external/generalization work.
3. Proper multilingual/Hindi/Hinglish labelled evaluation before any language-performance statement.
4. Human-review workflow, impact assessment, deployment policy, monitoring/privacy design, and incident response.
5. Deployment infrastructure: HTTPS/CSP/security headers, authentication/authorization where required, rate limiting, private networking, observability, rollback, and release automation.
6. Cross-browser and assistive-technology validation against the deployed build.

No roadmap item may be treated as completed without new evidence, registry/decision-log updates, and explicit approval.
