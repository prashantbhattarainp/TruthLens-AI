# Changelog

All notable changes are documented here. TruthLens AI remains a research-oriented project; release language never overrides the documented model governance boundaries.

## v1.0.0-RC1 — 2026-07-18

### Added

- Controlled release-candidate verifier for the existing public Node API path.
- Release, deployment, QA, migration, limitation, roadmap, and Phase 5 summary documentation.
- Original release-candidate architecture and prediction-workflow SVG diagrams.
- Local browser-captured prediction/explainability and dashboard-health evidence images.

### Changed

- README reorganized as an open-source RC entry point with installation, configuration, usage, architecture, API, model, research, visual, and roadmap references.
- Existing deployment documentation synchronized with the RC status and explicit no-database/no-public-release boundary.

### Unchanged by design

- Model, data, experiment results, calibration state, public API contract, backend architecture, ML service architecture, and persistence model.

## Phase 5.4 — Frontend hardening

- Added lazy route loading, loading skeletons, recoverable unknown-route state, accessible status/error feedback, safe modal/toast rendering, and responsive/accessibility QA.

## Phase 5.3 — Industrial analytics dashboard

- Added frozen-evidence dashboard charts, explicit privacy/no-retention states, local SVG visual asset, and user-triggered existing-endpoint health checks.

## Phase 5.2 — Prediction and explainability dashboard

- Added validated public prediction workflow and optional bounded SHAP/LIME metadata presentation.

## Phase 5.1 — UI/UX foundation

- Added the dependency-free application shell, design system, responsive navigation, and frontend documentation foundation.
