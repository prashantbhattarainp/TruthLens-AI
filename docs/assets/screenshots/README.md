# Screenshots

This directory contains screenshots used in the project README and documentation.

## Required Screenshots

| File | Description |
| --- | --- |

| `prediction-desktop.png` | Desktop prediction page |

## Adding Screenshots

Capture screenshots at 1280×800 (desktop) or 375×812 (mobile) resolution. Save as optimized PNG files and commit them to this directory.
