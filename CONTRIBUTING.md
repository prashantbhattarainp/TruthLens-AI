# Contributing to TruthLens AI

Thank you for contributing.

1. Create a branch from the current public release branch.
2. Keep changes focused and document user-visible behavior.
3. Do not add secrets, personal data, runtime packages, or other sensitive files.
4. Run the frontend tests, backend lint, and ML-service tests relevant to your change.
5. Open a pull request with a concise summary and validation results.

For bugs, include expected behavior, actual behavior, and safe reproduction steps. For security issues, do not publish sensitive details in a public issue.
